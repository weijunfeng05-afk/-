# V1.1 页面交互

登录：邮箱、密码；申请内测需要邮箱专属邀请码，注册后按邮箱验证流程登录。
首页：岗位数、候选人数、完成数、高优先级数与内测额度；岗位列表进入自己的工作台。
创建岗位：保存后立即进入后台生成状态，关闭页面也继续；失败可重试，完成后人工确认评分卡。
岗位工作台：候选人、岗位画像、评分卡；批量 PDF / DOCX 直传最多 30 份，每份 10 MB，上传并发 3；后台每用户最多 3 个分析任务。
评分卡已有候选人时显示锁定提示；修改需明确确认清空旧分数并重评。修改 JD 后重新生成、重新确认评分卡。
候选人显示等待/解析/评分/完成/失败，不用 0 分掩盖失败；失败可重试。
详情展示分项原文证据、优势、风险、未知项、核实问题、Must-have 三态及置信度。高分但 Must-have 证据不全或低置信度会提示核实。
页面仅在有运行任务且标签可见时每 3 秒刷新；回到前台立即刷新一次，完成后停止。
岗位底部记录分析统计和 HR 独立排序；排名不足 5 / 10 人时按有效样本数显示重合率。
设置默认使用平台额度，填写自己的 Key 为可选项；个人 Key 加密存储，移除后恢复平台服务。

所有优先级只用于决定先看谁，不作自动淘汰或录用决策。扫描 PDF 提示先 OCR；不虚构解析结果。
