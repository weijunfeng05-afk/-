# V1.1 Beta 范围与验收

本轮目标：注册登录 → 创建岗位 → 后台生成评分卡 → 人工确认 → 批量直传 → 后台分析 → 关闭页面仍可恢复 → 候选人排序，并隔离不同用户数据。

已实施：异步岗位及简历任务、持久并发名额、每分钟恢复、版本锁及全量重新评分、邮箱邀请码、平台密钥与可选 BYOK、额度、可解释结果、按需轮询、人工排序对比。

上线验收条件与运维操作见 [部署说明](NETLIFY-SUPABASE.md)。本地测试不替代真实 Netlify / Supabase / DeepSeek 联通和 5～20 位 HR 的真实脱敏简历评估。

暂不做：招聘平台 API、浏览器扩展、团队权限、ATS、人才库、邮件邀约、面试、Offer、支付与复杂分析大屏。

仍需真实用户验证：每岗位 10～50 份简历，独立人工盲排、Top5 / Top10 重合率、筛选耗时和误判案例；模型自报置信度尚未校准。
